Architecture

This viewer runs on a separate machine from the UAV stack. By default it pulls the RTSP stream and relays it to the browser as a plain HTTP multipart/x-mixed-replace MJPEG stream (no WebRTC/ICE, no extra ports — see VIDEO_DELIVERY_COMPARISON.md). The optional "WebRTC" stream mode instead spawns a local ffmpeg relay that pulls the same remote RTSP source, transcodes it to H.264 (WebRTC has no MJPEG codec support), and publishes it into a local mediamtx sidecar, which the browser then plays back over WebRTC/WHEP for lower latency — this works regardless of the remote pipeline's own RTSP encoding. Either way, it reads pipeline/model info from the DL Streamer Pipeline Server's REST API, proxies CPU/GPU/NPU utilization from metrics-manager, and bridges scene captions from MQTT — all via nginx on the remote host.
